Save ROC Team Image Instructions

To complete the ROC Availability Tracker, you need to save the ROC team image to the correct location.

Step 1: Right-click on the image below and select "Save Image As..."

Step 2: Navigate to the "l1-availability-tracker\img" folder

Make sure you save it in this exact location: l1-availability-tracker\img\roc-team.png

Step 3: Name the file "roc-team.png" and click Save

Ensure the file name is exactly "roc-team.png" (all lowercase)

Step 4: Refresh the ROC Availability Tracker page

After saving the image, go back to the tracker and refresh the page to see the image

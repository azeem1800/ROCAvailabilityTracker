How To See Your Roster Data

  1. Clear Your Browser Cache
    Press Ctrl+F5 (Windows) or Cmd+Shift+R (Mac) to force a complete refresh
  2. Open index.html
    Use this direct link: Open ROC Availability Tracker
  3. Verify Your Data
    You should see your custom roster data displayed in the "Currently Available Staff" section

Important: If you see a "Refresh Roster Data" button on the page, click it to ensure the latest data is displayed.

What's Changed?

The following improvements have been made:

  • Direct Data Integration
    Your custom roster data has been directly integrated into the application
  • Reliable Loading
    The application no longer attempts to read the CSV file, which caused browser security issues
  • Persistent Storage
    Your roster data is now saved in the browser's local storage for faster loading
  • Manual Refresh Option
    A refresh button has been added to force reload the data if needed

Alternative Viewing Options

In addition to the main index.html page, you can also use:

  • Direct Viewer
